## 2.6.6 - 2026-09-28

### 新增

- 桌面仪表盘新增侧边栏：Overview、Sessions Explorer、Stats & Heatmap、Usage Report、Quota & Budgets、Servers 与 Pricing DB 作为导航项，底部是 What's New 与设置，页眉提供深浅色快速切换，Sessions 页的筛选行则按所选周期内真正有会话的工具生成。手机宽度保留原有标签栏，并补上原先藏在侧边栏里的齿轮与 What's New 图标，因此 768px 以下仍可打开设置与切换语言。
- 会话详情现在会呈现各工具已经记录下来的信息：Hermes 会话的工作目录项目名与 git 分支、每个会话的工具调用与消息条数、配置档名称，以及 Hermes 与 Antigravity 会话的纯元数据消息时间线（角色、大小、token 数、时间戳、工具名）。转录文本不会读入 API，只有这些度量值会被送出。
- Overview 新增 Token Composition 区块，把当前时间窗的 token 拆分为 prompt、cache、output 与 reasoning，并在旁边给出缓存命中的现金价值。tokens_reasoning 现在经由计算层聚合，因此各部分相加等于总量。

### 调整

- 设置改为从侧边栏入口以弹窗形式覆盖在页面上。此前它渲染成挂在页眉下方的面板，而按钮却位于侧边栏底部，相隔近一屏；设置与 What's New 也各有两份（页眉一份、侧边栏一份），现在各保留一份。
- 浅色模式不再是"深色油漆刷在浅色墙上"。改版中硬编码的表面（#0d121f 卡片、#090d16 会话抽屉、白色半透明分隔线、深色系文本配默认 Paper 主题）已映射到主题令牌，因此卡片、KPI 网格、抽屉与滚动条会跟随所选样式主题，而不再是纯黑。每个可见字符串都经过实际测量而非目测：仪表盘在浅色与深色模式下都不再有低于 WCAG AA（4.5:1）对比度的文本，包括深色配色下几乎不可见的那些标签。
- 能耗/kWh 估算已移除。它的每 token 焦耳系数引用了仓库之外的研究笔记，而为其供数的模型匹配器会把 Kimi 识别为 llama-405b、把 Gemini 的任何 "pro" 识别为 claude-opus；Tokdash 不发布无法溯源的数字。成本本来就是那个一直存在的代理指标。
- 侧边栏与页眉的版本号改为读取运行中的包，而不是写死、且写下时就已过时的字面量。
- Z.ai 配额卡片改用 ZCode 标志，不再使用灰色字母占位块。该轮询本来就是从 ZCode CLI 自身的配置中读取 Z.ai 密钥，因此服务商映射表把 zai 指向包内已有的 ZCode 条目，而不是再打包一份同样的图形；Z.ai 卡片仍保留自己的标题，因此读起来依旧是 Z.ai。
- 不带子命令直接运行 tokdash 现在打印一屏命令卡（十一个动词分为四组，每组一行），而不是完整的参数参考。--help 仍是完整参考、仍列出每一个参数，但用法行收成一行，参数按小节排列，每节标题会列出读取它的每个动词，因此十二个参数不必各自重复一行 For tokdash quota consent。出错时同样只打印这段简短用法。

### 修复

- Hermes 会话保留真实的最后活动时间。此前某个版本的实现会在每个会话的 ended_at 处追加一个零 token 回合来拉长活跃时长，等于凭空记入消息之间数小时的空闲；伪造的回合已移除，Hermes 解析器版本保持为 1，因此升级后既有的解析缓存继续可用。
- Pi 分叉的重放只计一次。Pi 分叉会把父会话中已计费的助手事件复制进新的会话文件，而这些副本此前被当作新的用量读取——分叉一次就会抬高该会话触及的每一个汇总，分叉还会以整段历史都是重放出来的行出现在 Sessions 中。现在沿 parentSession 头部解析血缘，每个事件以经佐证的不可变字段作为键，因此原始会话拥有已记录的计费，后代只贡献自己的新工作，只有重放而没有新内容的会话会直接消失。血缘关系持久化在每个文件的缓存元数据中，因此删除祖先日志后重新打开仪表盘不会让同一次重放获得新的身份；Pi 解析器版本升到 2，会重建一次 v1 记录。

相关 PR：#110、#123、#125、#126

## 2.6.5 - 2026-09-26

### 新增

- 一台服务器可以绑定多个地址。设置界面按机器保留一个条目、每个地址一行，通过浏览器允许使用的最快地址读取，地址失联时自动切换下一个，因此再添一个地址不会把同一台机器的 token 重复计数。
- 地址在保存前会先探测：无应答、或应答为另一台 Tokdash 的地址会在输入处被拒绝并说明归属；浏览器确定无法读取的地址会标注被拦截及拦截规则，而不是被静默合并。

### 调整

- 配额卡片改用服务商自己的品牌图标 -- Codex、Claude Code、Antigravity、MiniMax、Kimi Code、Grok Build、OpenCode Go 与 Command Code -- 由统一的服务商到品牌映射表选取，图标与品牌色随来源注册表更新。Z.ai 是唯一仍使用字母占位图标的服务商。
- Report 页的 agent 表格打印所有记录到 token 的工具，不再把尾部折叠进 Other tools on this machine 展开项；没有会话记录的工具仍保留所在行，会话数与活跃时长以破折号占位。

### 修复

- TUI 周期视图的 [ / ] / 0 现在按完整日历周期翻页：月视图按一次显示上一个整月（而不是同一个整月少一天），周视图翻过整个周一至周日，年视图翻过整个自然年。
- 同一轮 TUI 评审的三个后续修正：textual 固定在 8.x，配额未启用的提示改为黄色而非字面 [warn] 标签，数据库状态读取移出事件循环，数据库变慢不再卡住按键响应。
- 固定型号的 Qoder CLI 现在能被统计。此前在 Qoder 设置里指定模型会让整个来源静默；Tokdash 现在从 CLI 自身的运行日志读取每个模型的上下文窗口，或读取会话声明的 --context-window，从而还原 CLI 填零的 token 数。完全没有窗口证据的模型会在告警中点名，而不再凭空消失。
- 统计 agy 1.2.x 的 Antigravity 用量。该版本不再写出行时间戳，而无时间戳的记录此前根本进不了用量存储；现在改为按所引用步骤中最新的时间为该行定日。

相关 PR：#117、#120、#116、#118、#119
