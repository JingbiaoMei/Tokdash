What does output tok/s mean?

One aggregate rate over calls with matched output tokens and timing. The session column uses the same rule for each response.

1,000 × Σ measured output tokens / Σ measured milliseconds
  • Server decode: an explicit server decode duration.
  • After first token: call duration minus recorded first-token latency.
  • Response window: a reconstructed model-response bracket, with verified tool time excluded.
  • Request window: message creation through completion, including request overhead.

Reasoning inclusion is stated for each group. Rates with different token bases stay separate. We do not average rates, use idle gaps, or estimate timing from active session time.

Coverage: measured calls / eligible output-producing calls. Low coverage may leave an unrepresentative subset. Small samples describe only those calls.

All data in this preview is fictional. Source timing association and token semantics still require validation before implementation.
